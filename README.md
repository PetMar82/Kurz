Toto je testovací repozitář

git clone - nakolonuje remote repozitář na lokální počítač
git status - ukaze v jakem stavu jsou soubory
git diff - ukaze presne zmeny v souboru
git add . - zastageuje
git commit -m "" - uloží změny
git push - pošle commit do GitHubu na remote
git pull - výtáhnestáhne nové změny z remote repozitáře z GitHubu
